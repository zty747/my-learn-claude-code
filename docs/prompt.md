分析代码时，应该有种固定的格式，让你分析数据流时，要张量+形状+实际意义。函数也要讲解功能与实际意义。

给我详细分析一下main文件中的parse_pdf函数做了什么，有以下规则：
1.不要跳过任意一条代码，但是分析中不必出现具体代码，你要将其转换为业务逻辑，说明其做了什么事情
2.要理清条件分支，比如不同prompt不同分支，image和pdf的分支
3.应该在这个过程抓住一个或几个对象的生命周期，如pdf是这么变为md的，列表又是这么维护的
4.调用的自定义函数页要按上面的方法展开分析 如果代码中有较详细的注释可以简单一点，比如post_process_cells
